# snack-finder

클로드 코드 **클라우드 예약 작업(Routines)** 으로 해외 간식·식품 소재를 1시간마다 자동 조사하는 저장소입니다.
컴퓨터를 켜둘 필요 없이 앤트로픽 클라우드에서 실행됩니다.

## 동작 방식
- 1시간마다 클라우드에서 실행
- 실행 시각에 따라 주제가 자동으로 바뀜 (round-robin)
- 조사 결과는 `results/` 폴더에 마크다운으로 쌓임
- 구체적인 절차는 [`CLAUDE.md`](./CLAUDE.md) 참고

## 설정 (한 번만)
1. claude.ai/code/scheduled 접속 → **New scheduled task**
2. 이 저장소(`snack-finder`)를 선택
3. 환경에서 **인터넷(웹 검색) 접근 허용**
4. 스케줄을 **Hourly** 로 설정
5. 프롬프트에 아래 한 줄 입력:

> 이 저장소의 CLAUDE.md에 적힌 '식품 소재 자동 탐색 루틴' 절차를 그대로 수행해줘. 현재 시각 기준으로 주제 하나를 골라 웹 검색으로 조사하고, results/ 폴더에 마크다운으로 저장한 뒤 커밋해줘.

## 결과 보기
- `results/` 폴더의 마크다운 파일
- 또는 claude.ai/code 의 각 실행 세션에서 확인
